# トリアージ ルーブリック

`vercel-toolbar-loop/references/comment-categories.md` の 4 分類を土台に、任意ソースの FB へ拡張したもの。

## 種別の判定

| 種別 | 見分け方 | 例 |
|---|---|---|
| バグ | 期待挙動が仕様に明記され、それと異なる | 「保存押すと500」 |
| 改善 | 動くが体験/品質の不満 | 「一覧が見づらい」 |
| 要望 | 今ない機能の追加 | 「CSV 出力したい」 |
| 仕様確認 | 仕様の曖昧/認識相違 | 「これ管理者も見える想定?」 |
| 重複 | 既出と同義 | 既存 #12 と同じ |

判断に迷ったら **仕様確認** に倒す（実装で握りつぶさない）。

## 優先度（P1/P2/P3）

```
優先度 = f(影響度, 頻度, ピッチ直結)
- P1: 主導線が壊れる / ピッチで必ず触る / データ毀損・セキュリティ
- P2: 重要だが回避策あり
- P3: あれば良い
```

## 出力フォーマット

```markdown
| # | FB(要約) | 種別 | 優先度 | 次アクション |
|---|---|---|---|---|
| 1 | 保存で500 | バグ | P1 | 修正 → smoke-test |
| 2 | CSV出力 | 要望 | P3 | spec-writer で要件化 |
| 3 | 管理者の閲覧範囲? | 仕様確認 | P2 | spec-writer に差し戻し |
```

## 振り分け先

- バグ → 修正 → `smoke-test` で回帰、`deploy-preflight`
- 改善（見た目）→ `design-review` / `shadcn-ui`
- 要望 / 仕様確認 → `spec-writer`
- 効果不明な改善 → `experiment-plan` で検証
- Toolbar 由来 → `vercel-toolbar-loop`
