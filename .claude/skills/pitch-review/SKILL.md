# pitch-review

## このスキルが解決すること

エンジニアの目で作ったプロトは「動く」が、ピッチ向けには:
- (CMO 視点) 訴求軸が不明確、誰の課題かわからない
- (CTO 視点) 「これ本当に作れる?」と疑念を抱かれる
- (CD 視点) 世界観がバラついて素人臭い

を踏みがち。このスキルは 3 役を順に演じ分けて検出する。

## 3 役 × 各論点

### CMO 視点

- 1 行で何のサービスかわかるか
- ターゲットユーザは誰か、その人が困っていることは何か
- なぜ今このサービスか (市場機会)
- 競合との差別化軸
- KPI / コンバージョンが想像できるか
- 価格戦略を口頭で説明できるか

### CTO 視点

- 実装の現実性 (フィクションの API / 存在しない技術ではないか)
- スケーラビリティ (ユーザ 1000 倍時に何が壊れる?)
- セキュリティ・コンプライアンス (PII / 監査・法令)
- データソース・ベンダロックイン
- 運用負荷 (oncall / 障害対応)
- コスト試算 (1000 ユーザ / 10 万ユーザ時)

### Creative Director 視点

- 世界観の一貫性 (フォント / カラー / トーン)
- 余白・グリッドの規律
- 画像・写真のクオリティ (素材感に手抜き感はないか)
- マイクロコピー (ボタン名 / placeholder / エラーメッセージ)
- 動きの品 (アニメーション速度 / イージング)
- 第一印象 5 秒のインパクト

## 出力フォーマット

```
## pitch-review レポート

### CMO 視点
[致命的]
- ターゲットが不明: ヘッダに「中小企業向け」とあるが、画面は個人ユーザに見える
  → ヘッダ近くに業種・規模・役職のセグメントを明示

[重要]
- ...

### CTO 視点
[致命的]
- ...

### CD 視点
[致命的]
- ...
```
