# インタビュー設計テンプレ

「あったら使う?」は当てにならない。**過去の具体的な行動**を聞いて、本当に存在する痛みだけを残す。

## 調査計画シート

```markdown
## 調査の目的
検証したい仮説: {idea-framing の不確実性 TOP3 から}

## 対象
- ペルソナ: {誰}
- 人数: {N=3〜5 で傾向、N=1 は仮説の発見用}
- リクルート: {どこで見つけるか}

## 方法
- [ ] 1on1 インタビュー(深さ重視 / 動機を掘る)
- [ ] アンケート(広さ重視 / 数で確かめる)
- [ ] 行動観察(言葉より行動を見る)
```

## 質問の型(誘導しない)

| 悪い問い(仮定・誘導) | 良い問い(過去の事実) |
|---|---|
| このアプリ使いますか? | 最近 {その作業} をしたのはいつですか? |
| 〇〇って便利ですよね? | その時、具体的に何をしましたか? |
| いくらなら払いますか? | 今そのために何かにお金や時間を使っていますか? |
| どんな機能が欲しいですか? | 一番面倒だったのはどの瞬間でしたか? |

## 深掘りの順序

1. **状況**: 最後にそれをしたのはいつ? どんな場面で?
2. **行動**: その時、実際に何をした? 何を使った?(= 代替手段 → competitive-analysis へ)
3. **障害**: うまくいかなかったのはどこ? どう回避した?
4. **動機**: なぜそれをする必要があった?(「なぜ」を 2〜3 回)

## 進め方の規律 (Naoya 3 原則)

- **相手のペースを奪わない**: 1 問投げたら沈黙を待つ。畳みかけない
- **「私が」で背負う**: こちらの仮説は「私の見立てでは」と前置きし、同意を急がせない
- **形式句を避ける**: 「ご意見ください」でなく、具体的な出来事を 1 つ思い出してもらう
