# AI 安全性チェックリスト

各項目を「OK / 要対応（致命/重要/望ましい）」で判定し、根拠を残す。

## 1. 不適切・有害出力
- [ ] システムプロンプトで役割・禁止事項を明示
- [ ] 末尾にプロンプトインジェクションガード文（ai-feature）
- [ ] 出力をそのまま HTML 描画していない（XSS/誤情報）
- [ ] 高リスク用途（医療/法務/金融助言）は免責 or 人手確認

## 2. 個人情報（PII）
- [ ] 入力に PII が入る経路を把握（フォーム/アップロード）
- [ ] プロンプト/ログに PII を残していない
- [ ] 出力に他者の PII が漏れない（RAG の取得範囲を権限で制限）
- [ ] 詳細な保存/削除/保存期間は privacy-check へ

## 3. ハルシネーション（事実性）
- [ ] 事実が要る箇所は RAG で grounding（context のみで答える）
- [ ] 根拠がないとき「分からない」を返せる
- [ ] 必要なら出典/引用を提示
- [ ] 数値・固有名詞の生成を検証（ai-eval の正確性観点）

## 4. 外部送信データ（egress）
- [ ] モデル/プロバイダに送る内容に機密/PII が含まれない
- [ ] 送信前マスキング（必要時）
- [ ] プロバイダのデータ利用ポリシー（学習利用の有無）を確認
- [ ] ゲートウェイ/プロキシ経由で送信先を制御（AI Gateway）

## 出力フォーマット

```
## ai-safety-check レポート
### 致命的
- [PII] RAG が全ユーザーの注文を取得 → 権限で絞る（auth-rules）
### 重要
- [hallucination] 価格を生成で出力 → data から取得に変更
### 望ましい
- [output] 過剰謝罪のトーン調整
```

> プロバイダのポリシー・モデル挙動は更新される。公開前に最新を確認すること。
