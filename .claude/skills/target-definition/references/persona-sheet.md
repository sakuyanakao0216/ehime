# ペルソナシート雛形

理想客の願望ではなく、`user-research` で会った実在の人を 1 人に凝縮する。

## ペルソナ(優先セグメントの代表 1 人)

```markdown
## ペルソナ: {名前(架空でも具体的に)}
- 属性: {業種 / 役職 / 年代 / 状況}
- 1 日の動き: {その用事が発生する場面}
- 今の困りごと(今日の痛み): {user-research の実発言に紐づけて}
- 今どう凌いでいるか(代替手段): {Excel / 手作業 / 他ツール → competitive-analysis へ}
- このプロトに期待する成果(Job): {状況→動機→成果}
- 判断基準: {何があれば「使う」と言うか}
- 根拠: {user-research の N=◯ / 代表発言}
```

> ペルソナは 1〜2 体に絞る。増やすほど焦点がぼやける。

## アンチペルソナ(今回は狙わない人)

スコープを締めるために**あえて狙わない人**を明示する。

```markdown
## アンチペルソナ
- {属性の人}: 理由 = {痛みが弱い / 到達できない / 要件が重すぎる}
```

例: 「大企業の情報システム部門 — セキュリティ要件が重く、プロト段階では狙わない」

## 使い方

- `competitive-analysis`: このペルソナの「用途」を比較軸の前提に置く
- `spec-writer`: PRD の「対象ユーザー / スコープ外」にそのまま転記
- 機能を足したくなったら「このペルソナが本当に使うか」で取捨選択する
