# キーレス画像生成のプロンプト設計 (ルート2: ログイン済みアプリで生成)

ChatGPT / Gemini アプリに貼るプロンプトの品質が、そのまま素材の品質になる。「リアルな写真」のような曖昧な指示は CG っぽいツルツルの画像を生む。**写真用語 (レンズ・ライティング・質感) で具体的に指示し、セット全体で一貫させる**のがこのドキュメントの方針。

## 原則 (全カテゴリ共通)

1. **共通スタイルブロック方式**: 複数枚のセットは「共通スタイルブロック (一字一句同じ)」+「被写体行 (差し替え)」の2部構成にする。スタイルが揃わない原因のほとんどは、毎回プロンプトを書き直すこと。
2. **同じチャットで連続生成**: セットは1つの会話内で生成し、2枚目以降は「**1枚目と同じライティング・背景・色味・構図で**」を必ず付ける。
3. **写真言語で指示**: 「リアル」ではなく「85mm 単焦点・浅い被写界深度・ソフトボックス光」のように、カメラマンへの発注のつもりで書く。
4. **質感の明示で AI っぽさを消す**: 「自然な肌の質感 (毛穴が分かる程度)、美肌フィルターなし、彩度控えめのナチュラルな色」を明示する。指定しないと過剰補正される。
5. **文字は画像に入れない**: 画像内テキストは滲む。見出し・ラベルは HTML/CSS で重ねる前提にし、必要なら「文字を重ねるための余白 (コピースペース)」を画像側に確保する。
6. **禁止事項を毎回添える**: 「実在の人物・有名人に似せない。テキスト・ロゴ・透かし・枠は入れない。」(著作権・商標は SKILL.md の「やってはいけないこと」参照)

## テンプレート集

【】内を差し替えて使う。アスペクト比はアプリ側で指定できない場合があるので、出なければ後述のトリミングで対応。

### 1. ペルソナポートレート (セット生成)

```
これから架空の日本人のビジネスポートレートを8枚、1枚ずつ生成します。
全枚で以下のスタイルを完全に統一してください:

【共通スタイル — 全枚同一】
85mm 単焦点レンズで撮影したような胸から上のスタジオポートレート。
浅い被写界深度。斜め前からの大型ソフトボックスの柔らかい光、目にキャッチライト。
背景は明るいニュートラルグレーの無地。
自然な肌の質感 (毛穴や産毛が分かる程度)、美肌フィルターなし、
歯は自然に、彩度控えめのナチュラルな色調。
正面からカメラ目線、口角を上げた自然な微笑。正方形 1:1。
実在の人物・有名人に似せない。テキスト・ロゴ・透かしは入れない。

1枚目の被写体: 【20代半ばの女性、黒髪ミディアム、ネイビーのジャケット】
```

2枚目以降は被写体行だけ送る: 「同じスタイルで次: 【30代後半の男性、短髪、チャコールグレーのジャケット、眼鏡】」。**服の色・髪型・眼鏡の有無をペルソナごとに明示して変える**と、UI に並べたとき見分けやすい。

### 2. hero 画像 (LP / トップ)

```
Web サービスのヒーローセクション用の写真を生成してください。
【明るいオフィスで、20〜30代の日本人2人がノート PC を挟んで打ち合わせをしている】シーン。
35mm レンズの自然なパース、大きな窓からの柔らかい自然光、
画面【右】1/3 は背景をぼかした余白にする (あとから見出しテキストを重ねるため)。
彩度控えめ、【ブランドカラーの青】系に寄せた色調。横長 16:9。
実在の人物・実在ブランドに似せない。画像内に文字・ロゴは入れない。
```

ポイント: **コピースペースの位置を明示**する (見出しが左なら余白も左)。UI に置いたときの完成形から逆算する。

### 3. OG 画像の背景 (1200×630)

```
SNS シェアカードの背景画像を生成してください。
【ブランドカラー: 青〜青緑】の抽象的なグラデーションに、
ごく薄い幾何学パターンを重ねたミニマルな背景。
中央〜左に大きめの無地領域を残す (サービス名を重ねるため)。
サムネイルサイズに縮小してもうるさく見えない、シンプルで上品なデザイン。
横長 1.91:1 (1200×630)。文字・ロゴは入れない。
```

サービス名・キャッチコピーは `app/opengraph-image.tsx` (next/og) でテキストとして重ねる (`seo-meta` プラグインの担当)。

### 4. 商品・モックアップ写真

```
EC サイト用の商品写真を生成してください。被写体: 【架空のスキンケアボトル、白基調のラベル (無地)】。
明るい白背景のテーブルに置き、やや上 45 度から。
ソフトボックスの均一な光、柔らかい影、商品にピントを合わせ背景は軽くぼかす。
ラベルに文字は入れない (無地)。正方形 1:1。実在ブランドに似せない。
```

複数商品はペルソナ同様に共通スタイルブロック+被写体差し替えで揃える。

### 5. イラスト (empty state / 機能説明)

```
Web アプリの空状態 (empty state) 用のフラットイラストを生成してください。
モチーフ: 【書類の入っていない受信トレイ】。
線の太さが一定のシンプルなベクター風、
配色は【ブランドカラーの青】+ そのライトトーン + ウォームグレーの3色のみ、
背景は白 (または透過)、装飾は最小限、中央配置で余白多め。正方形 1:1。
文字は入れない。
```

イラストセットは**配色 (3色) と線の太さの記述を全枚で固定**するとトーンが揃う。写真とイラストを同一画面に混在させない。

## リテイクの指示語 (よくある失敗 → 修正フレーズ)

| 症状 | 追加で送る指示 |
|---|---|
| 肌がツルツルで CG っぽい | 「美肌加工なしで。毛穴や産毛が分かる自然な肌の質感に」 |
| 色味・明るさが前の画像と違う | 「1枚目と同じライティング・背景・色温度で。構図だけ維持して撮り直し」 |
| 文字や記号が滲んで入った | 「画像内の文字・記号をすべて消して。文字は一切入れない」 |
| 構図が毎回ばらつく | 「頭頂から胸までのフレーミング、顔は画面中央、目線はカメラに固定」 |
| 背景がうるさい | 「背景は無地の【明るいグレー】1色に。小物・影の模様は消す」 |
| 笑顔が不自然 (歯が多い等) | 「口は閉じ気味の自然な微笑に。歯は見せすぎない」 |
| 彩度が高すぎて広告っぽい | 「彩度を落としてドキュメンタリー写真のようなナチュラルな色調に」 |
| 有名人っぽい顔になった | 「特定の実在人物に似ない、平均的な顔立ちに変えて」(似ている場合は採用しない) |

2〜3回のリテイクで直らない場合はプロンプトを直すより**新しいチャットでスタイルブロックから仕切り直す**方が早い。

## 生成後: 変換・配置パイプライン

アプリの書き出しは PNG/JPG なので、配置時に変換・縮小する:

```bash
mkdir -p public/images/persona
# npx で依存追加なしに変換+リサイズ (表示サイズの 2x 目安)
npx -y sharp-cli -i raw/persona-01.png -o public/images/persona/ -f webp resize 800 800
```

- sharp-cli が使えない環境では JPG/PNG のままでもよい (`next/image` が配信時に最適化する)。その場合もリサイズだけは行う (macOS: `sips -Z 800 raw/persona-01.png`)
- 命名・カテゴリは SKILL.md の保存ポリシー (`public/images/<category>/<purpose>-<index>.webp`) に従う

## 受入チェック (配置前に全枚確認)

- [ ] 画像内に文字・ロゴ・透かし・枠が入っていない
- [ ] 実在の人物・有名人・実在ブランドに似ていない
- [ ] セット内でライティング・背景・色味・フレーミングが揃っている
- [ ] 指・歯・目など細部に破綻がない (ポートレートは拡大して確認)
- [ ] 表示サイズの 2x 以下にリサイズ済み・1枚あたり概ね 200KB 以下
- [ ] ファイル名・カテゴリが保存ポリシー通り
