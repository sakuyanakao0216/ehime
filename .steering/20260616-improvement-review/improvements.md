## サマリー（現状認識）

構想・実装は厚い（concept-v3 正本／両輪モデル／AIマッチング `/api/match`／成立ゲージ／関わりの階段）。
最大の差別化（競合は"見る/申込"アグリゲーター、本アプリは **AI が参加・関わり・場を"創る"つくる側**で、
県主導の広域プールで**偏在を解消**し**指導者候補を育てる**）が、従来は**デモ第一画面で伝わっていなかった**のが最大の損失だった。
本レビューではここを最優先で是正した。

## 残りの改善点（優先度付きバックログ）

### P1（ピッチ前に着手したい）
| 観点(スキル) | 改善点 |
|---|---|
| design-review | 8軸（余白/タイポ/カラー/一貫性/レスポンシブ/コントラスト/インタラクション/実機）の本格点検。特にダークモードの全画面確認 |
| pitch-review | CMO/CTO/CD 3視点レビュー（訴求軸の一貫性・実装現実性とコスト・世界観の統一） |
| ai-safety-check | 匿名候補マッチングの公平性、未成年が関わる場の安全配慮、マッチ理由（reason）の説明可能性・誤誘導防止 |
| ai-eval | `/api/match` のプロンプト評価セットと回帰ケース固定（種目/地域/オンライン可否の代表ケースで劣化検知） |
| privacy-check | 嗜好・行動データ（観戦/チェックイン履歴）の取扱方針をピッチで提示できる形に。PII 非収集の明文化 |
| mockdata-ja / format-ja | 日付・人数・通貨表記の整形を `lib/format.ts` に集約し表示揺れを解消。モックのリアリティ底上げ |
| perf-check | LCP/CLS/INP 計測。地図SVG・画像・OG 生成のコスト確認 |
| smoke-test | 主要4画面（/ , /me , /operator , /instructors）が開く＋主導線クリックの Playwright スモーク |
| seo-meta | OG 画像の日本語版（JPフォント同梱 or デザイン素材）、favicon/app icon の案件カラー差し替え、sitemap/robots |

### P2（社会実装フェーズ）
| 観点(スキル) | 改善点 |
|---|---|
| api-contract / data-modeler | 実装の暗黙モデルを `api-contract.md` / `data-model.md` に明文化（正規化スキーマ・I/O仕様） |
| firebase-backend | 成立イベント・相談チャット・マッチ結果の永続化、実認証、ロール（参加者/募集側/行政） |

## 備考（差別化を“さらに”際立てるアイデア・任意）
