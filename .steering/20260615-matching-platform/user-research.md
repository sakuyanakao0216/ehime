# ユーザー調査 — 広域連携システム

> 作成日 2026-06-15。一次情報（スポーツ庁/文化庁ガイドライン、日本総研、各自治体人材バンク、報道）と
> 愛媛県推進計画の背景から構成。出典は competitive-analysis.md / insights.md 末尾に集約。

## ペルソナと課題（ジョブ理論ベース）

### P1. 運営者：南予の中学校 教頭・部活動主任
- 状況: 吹奏楽顧問が異動。校内に専門で見られる教員がいない。廃部を避けたい。
- ジョブ: 「専門外でも子どもの活動を止めずに、信頼できる指導者に任せたい」
- 痛み: 誰に頼めるか分からない／近隣に人材がいない／保護者に説明できる質保証がほしい
- 成功: 数日内に「研修済み・実績ありの指導者」と繋がり、保護者にも安心して説明できる

### P2. 指導者：松山在住・元実業団選手 / 企業勤務の体育会OB
- 状況: 平日夜と週末に余裕。地域に貢献したいが、報酬は期待していない。
- ジョブ: 「自分の専門を活かして子どもの役に立ちたい。続けるなら手応えと感謝がほしい」
- 痛み: 既存バンクは登録しても声がかからない／何が評価されるか不透明／移動負担
- 成功: オンライン併用で複数校に関われる／感謝・実績が見える形で残る

### P3. 指導者：南予在住の元教員（退職）
- 状況: 地元で時間がある。近隣校を手伝いたいが、制度・手続きが分かりにくい。
- ジョブ: 「手間なく登録し、近所の困っている部活に関わりたい」
- 痛み: 事務手続きの煩雑さ／一市町に閉じた募集しか見えない

### P4. 県・市町コーディネーター
- ジョブ: 「県全体で偏在をならし、空白地域に指導者を届けたい」
- 痛み: 市町任せで全体像が見えない／どこが手薄か数字で示せない
- 成功: 地域別の充足/不足が一目で分かり、重点投下の根拠になる

### P5.（間接）保護者・子ども
- 保護者の関心: 「誰が・どんな資格で・安全に」教えるか。費用と送迎負担。
- 子ども: 専門的に上手くなりたい／好きを続けたい。住む場所で機会が変わるのは不公平。

## 主要ユースケース（デモシナリオ）

1. **専門外の穴を広域で埋める**: 南予中学・吹奏楽 → 松山の元奏者がオンライン指導でマッチ
2. **空き時間を地域貢献に**: 企業OBが週末＋オンラインで複数校を掛け持ち
3. **偏在の発見と是正**: コーディネーターが「南予・特定種目ゼロ」をダッシュボードで発見し誘致
4. **保護者の安心**: 研修修了・資格・他校の感謝の声で「どんな人か」を確認して参加を決める

## インタビューで確かめたい仮説（社会実装前の検証項目）

- 「感謝の声・実績の可視化」は報酬の不足をどこまで補えるか
- オンライン指導は保護者・子どもにどこまで受け入れられるか（特に低学年・実技系）
- コーディネーターのダッシュボードは市町の行動を実際に変えるか
