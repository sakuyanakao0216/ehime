# 要求事項 — 広域連携システム（オールえひめ 部活動・地域クラブ指導者マッチング）

> 作成日 2026-06-15 / 機能名: matching-platform

## 背景 / 目的

愛媛県の部活動・地域クラブは「指導者などの協力人材の不足」と「地域間の偏り」に直面している。
直近10年で県内の部活動数は200以上減少、東予・南予では子どもの減少率が著しく、単独校での部活動維持が困難。
教員が専門外の競技まで顧問を担う形は心身の負担・長時間労働につながり持続性に欠ける。

県が主導し「オールえひめ」体制（市町・民間・大学・保護者と連携）で、子どもがどの地域にいても
専門的な指導を受けられる仕組み＝**広域連携システム**を構築する。
2026年12月にプロトタイプ完成、2027年から社会実装。愛媛で成功すれば全国へ横展開。

## 対象ユーザー（このプロトでデモする視点）

- **運営者**（学校・地域クラブ）: 指導者を募集・検索・依頼する。部活動の維持に困っている。
- **指導者**（協力人材）: 地域人材・専門家。登録・応募・研修受講。報酬以外の動機（やりがい・承認・地域貢献）。
- （参考視点）**県・市町コーディネーター**: 全体の偏在を俯瞰。今回はダッシュボードの一部要素として薄く反映。

## 調査から確定した「真のインサイト」（→ insights.md に詳細）

1. 既存の人材バンクは「登録して終わり」で死蔵する → **関わり続けたくなる体験**が差別化の本丸
2. 報酬がボランティア水準でなり手が増えない → **金銭以外の動機（承認・感謝・実績）** を設計で補う
3. 「どんな人か分からない不安」で学校が踏み込めない／保護者が心配 → **信頼レイヤー（研修・資格・実績・感謝の声）**
4. 地域偏在は単一市町で解けない → **県全体プール＋オンライン指導**で「どこにいても専門指導」
5. 送迎・移動・費用が参加障壁 → **オンライン/ハイブリッド**で障壁を下げる

## 要求（確定事項）

- [ ] 運営者・指導者の両視点の画面を用意する
- [ ] AI による広域マッチング（種目×地域×空き時間×オンライン可否）＋「なぜ合うか」の理由提示
- [ ] 候補カードに信頼レイヤー（研修修了・資格・実績・感謝の声）を常時表示
- [ ] 活性化機能: 県内アクティビティフィード／地域の盛り上がりメーター（東予・中予・南予）／マッチ成立演出／貢献バッジ
- [ ] みかんカラー（愛媛）のデザイントークン。ハードコード hex を本文で使わない
- [ ] モックデータ（faker ja）で愛媛の市町・種目・人材をリアルに表現

## スコープ外（今回やらないこと）

- 実 DB・実認証（モックで代替。社会実装フェーズで firebase-backend 等を配線）
- 決済・報酬支払いの実処理
- 研修コンテンツ本体・オンライン指導のビデオ会議実装（導線とモックで「存在」を示す）

## 受入条件

- [ ] `pnpm typecheck` / `pnpm build` が通る
- [ ] トップ→運営者→AI推薦→指導者 の一連がクリックで体験でき、ピッチで価値が伝わる
- [ ] 地域偏在と「どこでも専門指導」という愛媛の核が画面で表現されている
